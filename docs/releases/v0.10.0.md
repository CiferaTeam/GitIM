# GitIM v0.10.0

## 新功能

- 新增 Quick Session 协议、持久化、隔离执行、状态 API 与 CLI 管理工具
- 新增工作区级附件存储，支持流式写入、内容去重与安全 HTTP 访问
- 支持 Agent 上传、下载附件，并可跨 Fleet 节点解析与获取资源
- 新增规范化附件引用及类型化链接解析
- Fleet 支持持久化并验证 Runtime 身份
- Codex Provider 支持配置 reasoning effort

## 修复

- 修复 Quick Session 并发创建、归档、重试、恢复及冲突同步中的一致性问题
- 修复 Quick Session 过期回复、重复回复和队列输入丢失问题
- 修复 Runtime 异常中断后遗留 Provider Session 的问题
- 修复 Git 冲突重放失败时变更未恢复的问题
- 修复同步成功状态可能与远端实际提交不一致的问题
- 修复附件存储并发配额、损坏恢复、生命周期清理及初始化回滚问题
- 修复跨节点附件解析的回退、预算控制与元数据保留问题
- 修复工作区重新注册时附件及配置基线丢失问题
- 修复 Fleet 身份竞争可能选中非活跃实例的问题
- 修复 Daemon 并发启动时可能产生多个实例的问题
- 修复旧格式链接无法正确提取的问题

## 改进

- 消息搜索改为按需扫描消息文件，减少常驻索引状态
- 资源解析预算支持通过环境变量配置
- 附件去重命中时使用文件修改时间与大小进行快速校验
- 移除 Quick Session 每秒轮询，改进运行时资源占用
- 强化附件引用长度、媒体类型及存储边界校验
